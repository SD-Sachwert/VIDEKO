# Verpackungsgesetz / LUCID – Checkliste

Für den Versand von Ware an Endverbraucher gilt das **Verpackungsgesetz (VerpackG)**.
Diese Schritte sind **externe, rechtlich verpflichtende Registrierungen** – sie
können nicht im Code „erledigt" werden. Kein Punkt wird ohne echten Nachweis abgehakt.

## Pflichtschritte

- [ ] **LUCID-Registrierung** bei der Stiftung Zentrale Stelle Verpackungsregister
      (ZSVR) unter [lucid.verpackungsregister.org](https://lucid.verpackungsregister.org).
      Registrierungsnummer nach Abschluss hier notieren: `__________`
- [ ] **Vertrag mit einem dualen System** (Lizenzierung der Verkaufs-/Versand-
      verpackungen) abgeschlossen. Anbieter/Vertragsnr.: `__________`
- [ ] Gemeldete **Verpackungsmengen** (Karton, Füllmaterial, Polybeutel, Etiketten)
      hinterlegt.
- [ ] **Datenmeldungen** an LUCID und duales System aufeinander abgestimmt
      (Mengen müssen übereinstimmen).
- [ ] **Jahresabschlussmeldung** / ggf. Vollständigkeitserklärung im Kalender terminiert.

## Verantwortungsabgrenzung

- [ ] Geklärt, **wer** die Verpackung in Verkehr bringt (VIDEKO selbst vs.
      Fulfilment-/Druckdienstleister). Bei Fremdversand: schriftlich festhalten,
      wer die VerpackG-Pflichten übernimmt.
- [ ] Falls per Print-on-Demand/Dropshipping versendet wird: prüfen, ob der
      Dienstleister die Systembeteiligung übernimmt und dies belegen lassen.

## Status

**Nicht begonnen / extern durchzuführen.** Es liegen keine Registrierungs- oder
Vertragsnachweise vor. Diese Aufgabe ist ein **Blocker für den Verkaufsstart**.
