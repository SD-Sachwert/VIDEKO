VIDEKO – MASTERPROMPT UPDATE PAKET

Dieses Paket bündelt die bisherigen Journal-Vorgaben plus die neuen Korrekturpunkte.

Inhalt:
- 01_MASTERPROMPT_CLAUDE_KOMPLETT.txt
  Der zentrale Prompt für Claude. Damit soll Claude die betroffenen Bereiche sauber neu bauen.
- 02_JOURNAL_CONTENT_UND_FAQ.txt
  Inhalte für Journal-Artikel, FAQ, Frag-VIDEKO und Küchenmythen.
- 03_KURZCHECK_UMSETZUNG.txt
  Kompakte Prüfliste, damit Claude keinen Murks baut.
- assets/
  Referenzbilder für Journal, FAQ, Frag VIDEKO, CTA-Kontrast, kaputten Scrollbereich und das Über-uns-Team-Element.

Empfohlene Verwendung:
1. 01_MASTERPROMPT_CLAUDE_KOMPLETT.txt komplett in Claude einfügen.
2. 02_JOURNAL_CONTENT_UND_FAQ.txt zusätzlich mitgeben.
3. Die Referenzbilder aus assets/ anhängen.
4. Danach 03_KURZCHECK_UMSETZUNG.txt als Kontrollliste nutzen.

Ziel:
- Journal-Seite hochwertig finalisieren.
- Frag-VIDEKO-Bereich verbessern.
- CTA mit lesbarem Kontrast korrigieren.
- Kaputten Karten-/Scrollbereich ersetzen.
- Langweiligen Über-uns-Teamblock deutlich aufhübschen.
