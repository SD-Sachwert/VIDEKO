# VIDEKO Claude-Paket

In diesem ZIP sind:

- `CLAUDE_PROMPT.md` – kompletter Prompt für Claude/Claude Code
- `reference_images/` – die Screenshots als Referenzbilder mit klaren Dateinamen

Empfohlene Nutzung:

1. ZIP entpacken.
2. Die Referenzbilder in den Projektordner legen oder Claude im Chat mitgeben.
3. Den Inhalt aus `CLAUDE_PROMPT.md` in Claude einfügen.
4. Claude soll direkt im bestehenden VIDEKO-Code umbauen und danach Desktop/Mobile prüfen.
