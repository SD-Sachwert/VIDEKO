VIDEKO Stylefinder Paket

Enthalten:
1. CLAUDE_PROMPT_STYLEFINDER.txt
   -> Den kompletten Prompt in Claude Code einfügen.

2. assets/stylefinder_vorlage_mockup.png
   -> Visuelle Vorlage für den neuen Stylefinder.

3. assets/videko_aktuelle_designreferenz.png
   -> Aktuelle VIDEKO-Seite als Designreferenz.

Empfohlene Nutzung:
- Diesen kompletten Ordner ins Projekt oder in den Stylefinder-Aufgabenordner legen.
- Claude Code starten.
- Prompt aus CLAUDE_PROMPT_STYLEFINDER.txt einfügen.
- Claude ausdrücklich sagen, dass beide Bilder im assets-Ordner als Referenz genutzt werden sollen.
